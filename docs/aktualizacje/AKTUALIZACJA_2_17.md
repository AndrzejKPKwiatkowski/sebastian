# Sebastian 2.17 — Rekrutacja: nowy wygląd panelu

Wymaga wersji 2.16.3.

```bash
cd ~/SebastianSystem/sebastian-start && source .venv/bin/activate
python ~/Downloads/Sebastian_aktualizacja_2_17.py
```

Po instalacji odśwież panel w przeglądarce (Ctrl+F5 / ⌘⇧R).

| Element | Teraz |
| --- | --- |
| Czcionka | biznesowa i czytelna: Segoe UI (Windows), Aptos, Helvetica Neue (Mac); tekst 16 px, większa interlinia |
| Tło i karty | kremowe tło, białe karty z delikatną ramką i cieniem |
| Nagłówek | pasek w kolorze marki z logo „S”, aktywna zakładka podkreślona złotem |
| Oferty na listach | jak wyniki w portalu pracy: nazwa firmy w kolorze marki, dopasowanie w złotej plakietce, podświetlenie po najechaniu |
| Dopasowanie | ✓ / ◐ / ✗ w kolorowych kółkach (zielone, bursztynowe, czerwone) |
| Statystyki „Dziś” | karty ze złotym paskiem z lewej |
| Przyciski | prostokątne z zaokrągleniem, główny w kolorze marki, drugi z ramką |

**Kolory do wyboru** — Ustawienia → Jak pracuję → „Kolory panelu”: *Bordo i złoto* (domyślnie), *Butelkowa zieleń i złoto*, *Kremowy z karmelem*.
