# Sebastian 2.18 — Rekrutacja: punkty do CV, opisy do listów, wzory profilu

Wymaga wersji 2.17.

```bash
cd ~/SebastianSystem/sebastian-start && source .venv/bin/activate
python ~/Downloads/Sebastian_aktualizacja_2_18.py
```

Aktualizator robi kopię `fakty.json` (fakty.kopia-DATA.json) i dopisuje dane od Agi.

| Element | Teraz |
| --- | --- |
| Punkty do CV | przy każdym stanowisku pełna lista krótkich punktów Agi (np. 12 w ZZOZ, 17 w MEVLANA); Sebastian wybiera 3–4 najlepiej pasujące do wymagań i obowiązków z oferty (5 przy bardzo pasującym stanowisku), punkty z liczbami mają pierwszeństwo |
| Edytuj CV | przy każdym stanowisku „Wybierz punkty” — cała lista z polami do zaznaczenia i miejsce na własny punkt |
| Listy motywacyjne | dłuższe opisy stanowisk (nie trafiają do CV) jako fakty do listów i opisu |
| Opis „Profil zawodowy” | pisany na wzór 6 opisów Agi: 3–5 zdań, 1. osoba („Posiadam praktykę…”, „Wyróżniam się…”), jedna liczba z faktów, gdy pomaga; nadal tylko z faktów |
| Liczby | 10 transmisji i 8 wywiadów, ponad 100 planów, ok. 70 rozwiązań, 80 historii chorób, 40 opinii, 3 sprzedaże, 4 awanse, 3 konkursy |
| Kursy / narzędzia | EFG® – European Financial Guide (2025) (gdy go nie było), MS Office |
| Ustawienia → Twoje dane | nowe pola: dłuższy opis do listów przy stanowisku, wzory opisu profilu |

Stanowiska dodane przez aktualizację (jeśli ich wcześniej nie było) mają puste daty — trzeba je uzupełnić w Ustawieniach.
